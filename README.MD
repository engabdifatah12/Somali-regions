# 🇸🇴 Somali Regions & Capitals

A simple website that presents the regions of Somalia and their capitals.

## About

This project was created as a Git & GitHub Bootcamp Capstone project.

The main goal of the project is to demonstrate a complete Git and GitHub workflow, including:

- Git repository initialization
- Meaningful commits
- Feature branches
- Pull Requests
- Issues
- Code reviews
- GitHub Actions

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub Actions

## Features

- View Somali regions and capitals
- Search regions
- Responsive design
- Simple and accessible interface

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
